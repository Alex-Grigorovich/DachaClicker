Список апгрейдов для текущего кликера

Цель документа
- Подготовить набор апгрейдов, которые логично добавить в текущий прототип.
- Учитывать уже существующие системы: клики по овощам, деньги, посадка культур, открытие культур, слоты, локальный кулдаун.
- Сделать так, чтобы апгрейды можно было позже перенести в JSON или в отдельный менеджер апгрейдов.

Какие апгрейды подходят проекту сейчас лучше всего
- Апгрейды дохода за клик.
- Апгрейды скорости повторного клика / кулдауна.
- Апгрейды отдельных культур.
- Апгрейды поля и слотов.
- Апгрейды, которые усиливают раннюю и среднюю прогрессию, но не требуют сложных новых систем.

Рекомендуемая структура апгрейдов
- id
- название
- описание
- уровень
- максимальный уровень
- стоимость
- тип эффекта
- величина эффекта
- условие открытия

Блок 1. Базовые апгрейды клика

1. Сильнее клик
Суть:
- увеличивает доход за один клик по любой культуре.
Эффект:
- +1 к доходу за клик за каждый уровень.
Рекомендуемые уровни:
- 5
Пример стоимостей:
- 50 / 150 / 400 / 900 / 1800
Зачем нужен:
- это самый понятный и обязательный апгрейд для ранней игры.

2. Уверенная рука
Суть:
- ещё один базовый апгрейд силы клика, но более дорогой.
Эффект:
- +2 к доходу за клик за уровень.
Рекомендуемые уровни:
- 3
Пример стоимостей:
- 500 / 1500 / 4000
Зачем нужен:
- даёт игроку вторую линию роста после первого базового апгрейда.

3. Быстрый сбор
Суть:
- уменьшает локальный кулдаун у кликабельных культур.
Эффект:
- уменьшение cooldownTime на 5-8% за уровень.
Рекомендуемые уровни:
- 4
Пример стоимостей:
- 120 / 350 / 900 / 2200
Ограничение:
- не давать кулдауну уйти слишком низко, лучше оставить минимальный предел.

Блок 2. Апгрейды отдельных культур

4. Сочная морковь
Суть:
- увеличивает доход только от carrot.
Эффект:
- +1 / +2 / +3 к клику моркови.
Рекомендуемые уровни:
- 3
Пример стоимостей:
- 75 / 200 / 500
Зачем нужен:
- помогает первой культуре дольше оставаться полезной.

5. Крепкая капуста
Суть:
- увеличивает доход только от cabbage.
Эффект:
- +2 / +3 / +5 к клику капусты.
Рекомендуемые уровни:
- 3
Пример стоимостей:
- 250 / 700 / 1700

6. Спелый томат
Суть:
- увеличивает доход только от tomato.
Эффект:
- +4 / +6 / +9 к клику томата.
Рекомендуемые уровни:
- 3
Пример стоимостей:
- 800 / 2200 / 5000

7. Жгучий перец
Суть:
- увеличивает доход только от chili.
Эффект:
- +6 / +10 / +15 к клику перца.
Рекомендуемые уровни:
- 3
Пример стоимостей:
- 2500 / 6000 / 12000

Почему это полезно:
- игроку легче выбирать, усиливать ли весь аккаунт или любимую культуру.

Блок 3. Апгрейды прогрессии поля

8. Удобные грядки
Суть:
- снижает цену открытия следующей культуры.
Эффект:
- скидка 5-10% на разблокировку новых культур.
Рекомендуемые уровни:
- 3
Пример стоимостей:
- 300 / 1000 / 2500
Зачем нужен:
- помогает мягче пройти середину прогрессии.

9. Просторный участок
Суть:
- бонус к скорости прохождения квестов на заполнение слотов.
Эффект:
- даёт разовый денежный бонус при первом заполнении нового слота.
Рекомендуемые уровни:
- 1-2
Пример стоимостей:
- 500 / 2500
Зачем нужен:
- усиливает тему роста поля без добавления новой сложной механики.

10. Награда за развитие
Суть:
- повышает награды за квесты деньгами.
Эффект:
- +10% / +20% к денежным наградам квестов.
Рекомендуемые уровни:
- 2
Пример стоимостей:
- 700 / 2500
Зачем нужен:
- хорошо связывает систему апгрейдов и систему задач.

Блок 4. Экономические апгрейды

11. Первый капитал
Суть:
- стартовый бонус денег при запуске новой сессии.
Эффект:
- игрок получает небольшой стартовый капитал.
Рекомендуемые уровни:
- 3
Пример значений:
- +25 / +75 / +150 к старту
Пример стоимостей:
- 200 / 800 / 2500
Зачем нужен:
- особенно полезно для коротких сессий в браузере.

12. Золотая монета
Суть:
- шанс получить усиленный клик.
Эффект:
- 5-10% шанс получить x2 деньги за клик.
Рекомендуемые уровни:
- 3
Пример стоимостей:
- 1000 / 3000 / 7000
Примечание:
- добавлять только если хочется чуть больше азартного фидбека.

13. Выгодный урожай
Суть:
- общий процентный бонус ко всем кликам.
Эффект:
- +5% / +10% / +15% / +20%
Рекомендуемые уровни:
- 4
Пример стоимостей:
- 600 / 1800 / 4500 / 9000
Зачем нужен:
- хороший универсальный бустер в средней игре.

Блок 5. Апгрейды под будущие системы

14. Автосбор
Суть:
- раз в несколько секунд культура приносит доход без клика.
Эффект:
- включает пассивный доход.
Когда вводить:
- только после появления системы пассивки.
Почему не сейчас:
- в текущем прототипе это уже новая крупная механика, а не просто апгрейд.

15. Ускорение роста
Суть:
- культура быстрее возвращается в активное состояние после клика.
Эффект:
- дополнительное ускорение после базовых апгрейдов кулдауна.
Когда вводить:
- после стабилизации текущей экономики.

16. Комбо урожая
Суть:
- бонус за разные культуры на поле.
Эффект:
- если на поле 2-3 разные культуры, игрок получает общий бонус к доходу.
Когда вводить:
- когда появится желание поощрять разнообразие, а не только 3 одинаковые культуры.

Какие апгрейды стоит добавить первыми
- Сильнее клик
- Быстрый сбор
- Сочная морковь
- Крепкая капуста
- Выгодный урожай
- Награда за развитие

Минимальный набор для первой реализации
Если делать только самое нужное, достаточно 5 апгрейдов:
- Сильнее клик
- Быстрый сбор
- Сочная морковь
- Крепкая капуста
- Выгодный урожай

Рекомендуемая логика цен
- каждый следующий уровень должен стоить заметно дороже предыдущего;
- ранние апгрейды должны покупаться в течение первых 3-10 минут;
- средние апгрейды должны конкурировать с разблокировкой культур и слотов;
- поздние апгрейды не должны быть дешевле открытия редкой культуры.

Пример порядка открытия апгрейдов
1. Игрок получает доступ к "Сильнее клик" почти сразу.
2. После первых 100-200 денег открывается "Быстрый сбор".
3. После первой новой культуры открывается апгрейд конкретной культуры.
4. После 3-4 заполненных слотов открываются общие процентные апгрейды.
5. После завершения первой арки квестов открываются более дорогие экономические усиления.

Короткий вывод
Для текущего состояния проекта лучше делать апгрейды вокруг уже существующей механики клика, дохода и прогрессии поля. Самые полезные первые апгрейды: сила клика, скорость клика, бонусы конкретным культурам и общий процентный доход. Они понятны игроку, легко балансируются и хорошо подходят для браузерного кликера.
